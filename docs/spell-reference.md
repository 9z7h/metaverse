# 기본 주문 원작 대응표

사신학당의 기본 주문 네 가지가 해리포터에서 어떤 주문에 해당하는지, 원작에서 무슨 역할을 하는지 정리한 참고 문서입니다. 앱의 주문 기준은 [사신학당 마법 기준](magic-standards.md)을, 세계관 원칙은 [세계관 기준](world.md)을 따릅니다.

- 이 문서는 **내부 참고용**입니다. 앱 화면 문구, 코드 주석, 커밋 메시지에는 원작 주문 이름을 쓰지 않고 한글 이름(명경·묵령·화룡·부운)만 씁니다.
- 원작 내용은 공식 자료를 다시 조회하지 않고 알려진 설정을 기억에 따라 적었습니다. 설정집에 반영하기 전에 공식 자료로 확인해야 합니다.
- 사신학당의 주문은 원작을 그대로 옮기지 않은 한국식 재해석이며, 공식 설정과 무관한 창작입니다.

| ---------- | --------------------------------------- | ---------------------------- | ------ |

## 주문별 설명

### 명경 ↔ 루모스

- **원작**: 지팡이 끝에 빛을 내는 주문입니다. 어두운 곳에서 손전등처럼 쓰며, 지팡이를 든 채 걸을 수 있습니다. 이어서 빛의 세기나 범위를 키우는 변형도 있습니다.
- **역할**: 탐색과 이동을 돕는 가장 기본적인 보조 주문입니다. 공격이나 방어가 아니라 시야를 확보하는 용도입니다.
- **사신학당의 해석**: 지팡이 끝에서 밝은 흰빛이 나와 주변을 비춥니다. 빛은 시전자를 따라 움직이며 묵령으로 끌 때까지 유지됩니다.

### 묵령 ↔ 녹스

- **원작**: 루모스로 켠 빛을 끄는 짝 주문입니다. 같은 지팡이 불빛을 되돌리는 쓰임이라, 빛 주문의 "끄기" 역할을 맡습니다.
- **역할**: 빛을 거두어 은신하거나 들키지 않게 하고, 켠 주문을 정리합니다.
- **사신학당의 해석**: 먹이 번져 사라지는 모습으로 자신의 명경만 흩어지게 합니다. 남의 불빛이나 석등·등잔 같은 공용 물건은 끄지 않습니다. 약 1.2초 걸립니다.

### 화룡 ↔ 인센디오

- **원작**: 불꽃을 일으키는 주문입니다. 지팡이에서 불길이 나가 물건에 불을 붙이거나 불을 지피는 데 씁니다.
- **역할**: 점화와 소각, 때로는 공격에도 쓰이는 불 계열 기본 주문입니다. 원작에서도 위험한 편이라 조심해서 다룹니다.
- **사신학당의 해석**: 피해를 주지 않는 작은 붉은 불꽃이 용처럼 구불이며 날아가 자리에 작은 불꽃을 남깁니다. 약 8초 뒤 사라지며 아무것도 태우지 않습니다.

### 부운 ↔ 윙가르디움 레비오사

- **원작**: 물건을 공중에 띄우는 부양 주문입니다. 1학년 마법 수업에서 깃털을 띄우는 연습으로 처음 배우며, 발음을 정확히 해야 한다는 장면과 지팡이를 "휙 젓고 튕기는" 동작으로 널리 알려져 있습니다. 위기 상황에서 무거운 물건을 띄워 쓰는 장면도 나옵니다.
- **역할**: 사람이 직접 들기 어려운 물건을 옮기거나 움직이는 이동·조작 주문입니다.
- **사신학당의 해석**: 작은 조약돌 하나가 흰 구름 조각 위로 떠올랐다 내려옵니다. 물건만 띄우며 사람은 띄우지 않습니다. 사람이 나는 일은 빗자루(구름 타기)가 맡습니다. 약 6초 유지됩니다.

### 수련으로 푸는 주문 (원작 주문명은 적지 않음)

| 사신학당       | 원작에서의 역할                                            | 단축키 | 풀리는 때  |
| -------------- | ---------------------------------------------------------- | ------ | ---------- |
| 소신(小身)     | 대상을 작게 줄이는 주문                                    | 5      | 누적 1시간 |
| 거신(巨身)     | 대상을 크게 키우는 주문(소신의 짝)                         | 6      | 누적 1시간 |
| 은형(隱形)     | 시전자를 주변 풍경에 녹아들게 하는 은신 주문               | 7      | 누적 3시간 |
| 수호령(守護靈) | 마음속 행복한 기억으로 수호 짐승을 불러내는 고급 방어 주문 | 8      | 누적 5시간 |

원작 주문명은 이 문서에도 새로 적지 않습니다. 사신학당의 해석은 [사신학당 마법 기준](magic-standards.md)의 "수련으로 푸는 주문"을 따릅니다. 수호 짐승은 원작처럼 각자의 상징이 아니라 한국 신수인 백호의 윤곽으로 통일했고, 적을 막는 기능은 없는 연출입니다.

## 원작과 달라진 점

| 항목        | 원작                         | 사신학당                                          |
| ----------- | ---------------------------- | ------------------------------------------------- |
| 이름        | 라틴어풍 주문                | 한자어 두 글자(명경·묵령·화룡·부운)               |
| 발동        | 주문을 소리 내어 외움        | 지팡이를 휘두르는 동작과 숫자키                   |
| 범위        | 대상을 겨눔                  | 명경은 지팡이 끝, 다른 주문은 시전자 앞 작은 구역 |
| 공유        | 세계에 실제 영향을 줌        | 시전자별 개인 효과, 공용 물건은 바꾸지 않음       |
| 위험        | 불·부양은 사고가 날 수 있음  | 피해와 경쟁·점수 요소 없음                        |
| 묵령의 상대 | 루모스 외에도 지팡이 빛을 끔 | 자신의 명경에만 작용                              |

## 반영 상태

- 이 대응은 설계 단계에서 사용자가 제시한 네 주문(명경·묵령·화룡·부운) 아이디어에 따른 것입니다.
- 소신·거신·은형·수호령은 이후 사용자가 직접 고른 네 주문입니다.
- 원작의 다른 주문(무장 해제, 방어막 등)은 아직 대응시키지 않았습니다. 추가하려면 [사신학당 마법 기준](magic-standards.md)의 즉시술 한계(범위, 지속, 동시 개수)를 먼저 정해야 합니다.
