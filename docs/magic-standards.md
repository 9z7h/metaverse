# 사신학당 마법 기준

이 문서는 사신학당의 마법 설정과 현재 앱의 주문 시전 기준을 정리합니다. 세계관의 기본 원칙은 [세계관 기준](world.md)을 따릅니다. 주문 이름과 세부 연출은 앱에서 보강한 내용으로, 설정집에 반영할지는 별도 확인이 필요합니다.

## 세계관의 기본 원칙

> 힘에는 공급원이, 술식에는 범위가, 약속에는 상대가 있다.

마법은 어려운 일을 도울 수 있지만 무한한 결과를 만들지는 못합니다. 대상이 크거나 멀어지면 부담이 커지고, 다른 존재와의 연결에는 상대의 동의가 필요합니다. 마법의 결과가 주변에 미치는 영향도 시전자가 책임집니다.

| 술식      | 쓰임                                                         | 한계                                                      |
| --------- | ------------------------------------------------------------ | --------------------------------------------------------- |
| 즉시술    | 손짓, 말, 도구로 잠시 움직이거나 작은 방어막을 만듭니다.     | 집중이 풀리면 약해지며, 크고 먼 대상에는 부담이 커집니다. |
| 기록술    | 종이나 물건에 조건을 남겨 빛, 보온, 보관, 알림을 유지합니다. | 준비가 필요하며 기록이 훼손되면 효과가 약해집니다.        |
| 맺음술    | 장소, 물건 또는 동의한 존재 사이를 연결합니다.               | 상대의 동의와 매개가 필요합니다.                          |
| 합동 진법 | 여럿이 위치와 호흡을 맞춰 큰 공간을 보호합니다.              | 한 사람이 다른 사람을 대신할 수 없습니다.                 |

## 앱의 기본 주문

다음 네 주문은 앱에서 보강한 즉시술 연출입니다. 명경의 빛은 지팡이 끝을 따라 움직이고, 다른 주문은 시전자 앞의 작은 구역에 일시적인 효과를 냅니다.

| 키  | 주문       | 효과                                              | 지속 시간 |
| --- | ---------- | ------------------------------------------------- | --------- |
| 1   | 명경(明鏡) | 지팡이 끝에서 밝은 흰빛을 냅니다.                 | 끌 때까지 |
| 2   | 묵령(墨靈) | 자신의 명경을 먹물처럼 흩어지게 합니다.           | 약 1.2초  |
| 3   | 화룡(火龍) | 작은 붉은 불꽃이 용처럼 움직이고 불꽃을 남깁니다. | 8초       |
| 4   | 부운(浮雲) | 작은 조약돌을 구름 조각 위로 띄웠다가 내립니다.   | 6초       |

명경과 묵령은 하나의 토글 버튼으로 표시하며, 숫자키 1 또는 2로 켜고 끌 수 있습니다. 빛은 끄기 전까지 유지됩니다.

## 시전과 표시 기준

- 먹빛각과 숨돌림 뜰에서 시전하며, 같은 공간에 있는 다른 사람에게 효과를 보여 줍니다.
- 앉아 있을 때는 시전하지 않습니다. 숨돌림 뜰에서는 구름을 타고 있어도 시전할 수 있습니다. 먹빛각에서 순위판을 보는 동안에도 시전하지 않습니다.
- 입력란에 글을 쓰는 동안에는 숫자키 주문을 실행하지 않습니다.
- 명경을 제외한 효과의 기준 구역은 시전자 앞 1.6m를 중심으로 하며 반지름은 1.2m입니다. 묵령의 연기는 지팡이 가까이에서 나타납니다.
- 명경·묵령 토글의 쿨타임은 0.5초, 화룡은 8초, 부운은 6초입니다. 화룡과 부운은 각각 독립적으로 쿨타임을 계산합니다. 지팡이를 휘두르는 연출은 1.2초입니다.
- 명경을 제외한 일시적인 주문 효과는 한 장면에서 최대 6개이며, 효과 하나의 파티클은 최대 24개입니다. 새 효과가 상한을 넘으면 오래된 효과부터 정리합니다.
- 주문은 등잔, 석등과 같은 공용 물건의 상태를 바꾸지 않습니다. 묵령은 자신의 명경에만 작용합니다.
- 주문 연출은 경쟁이나 점수에 사용하지 않습니다. 사신제의 수련 시간과 공적도 서로 다른 기록입니다.

## 확인과 유지 관리

주문 이름과 효과의 설정집 반영 여부는 **확인 필요**입니다. 숫자, 지속 시간, 효과 범위가 바뀌면 [주문 규칙 코드](../src/components/pages/Library/scene/spellLogic.ts)와 이 문서를 함께 갱신합니다. 앱의 3D 실습 마법진은 별도의 시각 연출이며 특정 술식으로 확정하지 않았습니다.
